St Peter's Budokomi Fees Management System

## Project Description
A web-based platform that allows schools to record student fee payments and automatically notify parents of their updated fee balance via SMS. The system aims to eliminate receipt delays and disputes between schools and parents by providing real-time fee balance updates.
